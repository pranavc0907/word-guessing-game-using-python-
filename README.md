# 🎮 Python Word Guessing Game

A Python mini project developed in stages to demonstrate the progression from learning programming fundamentals to enhancing an application with AI-assisted development, culminating in a standalone browser-ready web version.

---

## 📌 Project Overview

This project contains three implementations of the same Word Guessing Game:

### 1️⃣ gamecode.py – Base Version

The original command-line implementation created while learning Python fundamentals.

**Concepts Used**
- Variables
- Lists
- Random module
- Loops
- Conditional statements
- Functions
- User input
- Score tracking

**Features**
- Random word selection
- Hint system
- Limited attempts
- Score calculation
- Play again option

---

### 2️⃣ game-ai.py – Enhanced Version

An improved version of the same game where the original logic was retained while AI was used as a development assistant to improve the user experience and interface. Runs locally using a Python HTTP server.

**Enhancements**
- Improved UI/UX
- Better game flow
- Cleaner code organization
- Additional visual feedback
- More engaging gameplay

---

### 3️⃣ index.html – Deployed Static Web Version

The standalone client-side version of the enhanced game. It has the exact same UI, audio, and animations, but runs entirely in the browser using pure client-side JavaScript. This is ideal for instant web deployment.

**How to run**: Open [index.html](file:///c:/Users/pc200/OneDrive/Documents/Projects/build-a-word-guessing-game-with-python/index.html) directly in any web browser.
