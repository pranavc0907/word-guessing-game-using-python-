# 🎮 Python Word Guessing Game

A Python mini project developed in two stages to demonstrate the progression from learning programming fundamentals to enhancing an application with AI-assisted development.

---

## 📌 Project Overview

This project contains two implementations of the same Word Guessing Game.

### 1️⃣ gamecode.py – Base Version

The original command-line implementation created while learning Python fundamentals.

**Concepts Used**
- Variables
- Lists
- Random module
- Loops
- Conditional statements
- Functions
- User input
- Score tracking

**Features**
- Random word selection
- Hint system
- Limited attempts
- Score calculation
- Play again option

---

### 2️⃣ game-ai.py – Enhanced Version

An improved version of the same game where the original logic was retained while AI was used as a development assistant to improve the user experience and interface.

**Enhancements**
- Improved UI/UX
- Better game flow
- Cleaner code organization
- Additional visual feedback
- More engaging gameplay
